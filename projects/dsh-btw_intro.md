# dsh-btw — DeepSeek Harness 旁问插件

DeepSeek Harness（网页版）插件：在当前会话里顺手问一句，不打断主任务。输入 `/btw 问题`，或在回复里选中文字后点「旁问」，回答显示在对话流里的卡片上。用来替换 `@michengai/dsh-btw`（两个插件都注册 `/btw`）。

## 技术栈

- DSH 插件（Cordis），TypeScript；网页端卡片、侧边栏和设置页为 React
- 测试：Vitest + Testing Library（jsdom）
- `node build.js` 做类型检查、生成 `lib/`、打包浏览器端并自检

## 主要能力 / 亮点

- **默认用会话自己的模型**：会话还没发过请求时用 `deepseek-flash`、推理强度 low；插件页可以改成「指定模型」并选模型和推理强度。唯一能用的工具是联网搜索，默认最多 4 轮。
- **不再乱调工具**：旧插件把主会话整段 fork 给子代理，历史里全是工具调用，请求里却没有工具定义，模型因此不停尝试调工具。本插件把主会话历史展平成纯文本再交给模型，只声明 `web_search` 一个工具，其他调用一律返回错误；收尾请求不带任何工具。
- **划词旁问**：「旁问」和宿主的「引用文本」放在同一个浮条里，点击后浮条原地变成提问框；卡片插在被划词的那条回复下面。
- **卡片管理**：可复制、折叠、删除；删除写进会话记录，刷新后也不会回来，回答中删除会中止。右侧边栏的「旁问历史」页列出当前会话的全部旁问，可一键定位。
