# Digit OCR — 用 C++17 从零手写的手写数字识别

用 C++17 从零实现 MLP 与 CNN 两种网络做手写数字识别，只依赖标准库，在 MNIST 上训练；OpenCV 只用来预处理输入图片。

## 技术栈

- C++17，CMake（≥ 3.20）
- OpenCV：只用于读入并预处理待识别的图片
- 数据：MNIST 原始 IDX 文件（训练集与测试集随仓库提供）

## 主要能力 / 亮点

- **两种网络都只用 STL 手写**：前向传播、ReLU、softmax 与反向传播（随机梯度下降）；CNN 另有卷积、最大池化与展平层。
- **自写 MNIST 解码器**：直接读取 `train-images-idx3-ubyte` 等原始 IDX 文件。
- **图片预处理**：灰度读入、Otsu 二值化、按外接矩形裁到数字区域、`INTER_AREA` 缩放。
- **权重持久化**：训练好的 MLP 与 CNN 权重存成二进制文件并可重新载入，预测无需重新训练。
