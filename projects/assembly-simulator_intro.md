# Assembly Simulator — 浏览器里的 MIPS 汇编教学 IDE

在浏览器里写、汇编、单步运行 MIPS 汇编的教学工具。指令集和行为对齐 **MARS 4.5**，但引擎是自己写的，网页里不含任何 MARS 代码；MARS 只用来生成测试的标准答案。构建结果是一个独立的 `index.html`，放在 GitHub Pages 上能用，下载到本地双击也能用，不需要联网。界面中英双语，可切换浅色和深色主题。

## 技术栈

- TypeScript + Vue 3 + Vite（`vite-plugin-singlefile` 打成单个 HTML）
- 编辑器：CodeMirror 6
- 测试：Vitest（单元测试、对 MARS 标准答案逐项比对、AGENTS.md 检查）；`vue-tsc` 类型检查
- 部署：GitHub Actions 在每次 push 到 `main` 时跑测试和构建，发布到 GitHub Pages

## 主要能力 / 亮点

- **对齐 MARS 4.5**：全部 155 条基本指令（整数、HI/LO、SPECIAL2、陷阱、CP0、单双精度浮点）和每一种伪指令写法，展开方式与 MARS 相同；汇编指示（包括 `.macro`、`.eqv`、`.include`）、全部 39 个 syscall（输入在终端里打字，31/33 真的发声，40–44 与 MARS 同一随机数算法）、异常与 `.ktext` 处理程序，内存布局与 MARS 默认配置一致。
- **拿 MARS 本身做验收**：测试程序和全部示例程序事先在 MARS 4.5 上跑过，机器码、数据段、终端输出、最终寄存器和报错作为标准答案提交进仓库（46 份：39 个测试程序 + 7 个示例）；另有差分测试（约 5 万行指令、8 千行数据、2000 个随机程序、130 个 syscall 用例）。引擎每秒约 500 万条指令。
- **编辑运行**：CodeMirror 编辑器带语法高亮、仿 VS Code 的自动补全，⌘/Ctrl 点击指令打开指令集、点击标签或宏跳到定义；改完代码无需单独汇编。单步可按源码行或按真指令，运行按约 12 毫秒一段执行、页面不卡、随时可暂停，另有自动单步和最多 2000 步的撤销。寄存器按「未用 / 读过 / 写过」着色，栈、内存、机器码视图同步高亮。
- **指令集与反汇编**：选一条指令或输入一行汇编，把机器码按位域画出来并在真模拟器上执行一遍；输入机器字可反汇编出汇编文本、位域和说明。
- **为别的架构留了接口**：引擎通过 `IsaPlugin` 接口接入，ARM64 和 x86-64 已出现在架构选择里，但尚未实现。

## 当前状态

- 进行中。仓库首次提交 2026-11-18；v0.1.3（2026-11-19 打 tag），MIT 许可。
- 测试：11 个测试文件 / 174 个用例（v0.1.3 上 `vitest run` 的结果）。
- 有意不做：MARS 的工具（MMIO 键盘与显示、位图显示等）、延迟分支、紧凑内存配置。有意比 MARS 更严格：MARS 会悄悄生成错误程序的几种情况（如 `.data` 里写指令、超过 32 位的整数、超出 16 位范围的分支）在这里直接报错。
- 目标：在同一个 `IsaPlugin` 接口后面实现 ARM64 和 x86-64。
